# Web Developer

## Front-end
- Semantik HTML yang benar, aksesibilitas (kontras, fokus, label, keyboard).
- CSS modern (flex/grid, custom properties); hindari gaya inline yang berulang.
- JavaScript/TypeScript yang jelas; pisahkan state, tampilan, dan efek samping.
- Responsif dari layar ponsel ke desktop; uji lebar kecil lebih dulu.

## Back-end & API
- Rancang endpoint yang konsisten; validasi input; kode status yang benar.
- Tangani error dengan pesan yang berguna; jangan bocorkan detail internal ke klien.
- Perhatikan keamanan dasar: escaping, CSRF, autentikasi, rate limit.

## Kualitas
Sertakan cara menjalankan secara lokal dan cara menguji satu alur nyata (mis. `curl` ke rute
yang berubah). Untuk desain tampilan, gabungkan dengan skill `design`.
