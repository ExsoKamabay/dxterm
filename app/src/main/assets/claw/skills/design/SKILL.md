# Design (UI / UX / TUI)

Tolak tampilan "standar" yang datar. Setiap desain harus punya keputusan sadar soal gaya,
warna, tipografi, ruang, dan gerak.

## Dasar
- Warna: tetapkan token (latar, permukaan, teks, aksen, status). Jaga kontras cukup untuk
  dibaca (teks penting minimal rasio 4.5:1). Sediakan mode gelap dan terang.
- Tipografi: pilih pasangan font dengan tujuan; atur skala ukuran dan tinggi baris yang enak.
- Ruang: skala spasi yang konsisten; beri napas, jangan padat.
- Hierarki: satu titik fokus per layar; ukuran dan warna mengarahkan mata.

## UX
Rancang alur, bukan sekadar layar. Kurangi langkah, beri umpan balik jelas, dan buat jalur
gagal tetap ramah.

## TUI / CLI
Terminal juga layak didesain: pakai warna dan bingkai yang konsisten, sejajarkan kolom,
hormati lebar sempit, dan sediakan fallback saat warna dimatikan. Jangan andalkan emoji lebar
untuk tata letak.

Untuk implementasi web pakai `web-dev`, untuk Android pakai `android-dev`.
