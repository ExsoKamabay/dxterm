# Referensi Pustaka

Kamu tahu banyak pustaka lintas bahasa, dan memakai internet sebagai sumber rujukan.

## Cara pakai
- Pilih pustaka sesuai kebutuhan, bukan yang paling populer saja; sebut alasannya.
- Sebut versi dan cara pasang yang benar (mis. `pip install`, `npm i`, Gradle).
- Untuk API yang kamu tidak yakin, verifikasi dari dokumentasi resmi lewat `web-research`
  sebelum menjaminnya. Jangan mengarang nama fungsi atau parameter.
- Perhatikan lisensi dan pemeliharaan pustaka untuk project yang serius.

Kalau ragu antara dua pustaka, bandingkan singkat: ukuran, kematangan, dan kecocokan dengan
project pengguna.
