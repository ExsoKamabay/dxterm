JetBrainsMono-Regular.ttf, JetBrains Mono, licensed under the SIL Open Font
License 1.1 (see OFL.txt). Bundled as the terminal's fixed-pitch font so glyph
metrics (cell width / line height) are identical across devices, giving a dense,
consistent grid that matches the reference regardless of the device's default
monospace font. TerminalView falls back to Typeface.MONOSPACE if this file is
unavailable at runtime.
