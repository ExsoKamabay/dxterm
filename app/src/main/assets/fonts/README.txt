Bundled monospace fonts for the terminal. The user picks one in xset > Font >
Font family; TerminalView loads it from this folder and falls back to the
platform monospace (Typeface.MONOSPACE) if an asset is unavailable at runtime.
JetBrains Mono is the default: its glyph metrics give a dense, consistent grid
across devices.
