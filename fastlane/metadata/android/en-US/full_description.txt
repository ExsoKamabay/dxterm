dracxterm is a terminal for Android. Use it as it comes to type commands, or install
Linux inside it and work the way you would on a computer. No root needed.

<b>Terminal</b>

<ul>
<li>Colours, cursor shapes, scrollback and the alternate screen for full-screen programs</li>
<li>UTF-8 text, including wide scripts such as CJK</li>
<li>Select text, search the screen, copy and paste</li>
<li>Mouse support for programs that use it</li>
<li>Up to five workspaces, each with its own shell and history. Swipe to switch</li>
<li>Sessions keep running when you switch to another app</li>
<li>An extra key row: arrows, Ctrl, Alt, Esc, Tab, Home, End, PgUp, PgDn, paste, search
and zoom</li>
<li>Pinch the screen to change the font size</li>
</ul>

<b>Settings</b>

Type <i>xset</i> in the terminal to open the settings. They are drawn inside the terminal
with a live preview: theme, font, text size and spacing, cursor shape, scrollback length,
storage access and device details. Settings can be exported and imported again.

<b>Linux</b>

With nothing installed, the app already gives you a working shell. If you want a full
distribution, the app can install one inside its own storage. Inside the distro,
<i>sudo</i>, <i>su</i> and <i>apt</i> work as usual, and .deb packages install with
<i>dpkg</i>.

On first run the app lists the distros your device can run, with the download size for
each. Downloaded files are checked before anything is installed, so a corrupted or
altered file never gets unpacked. There is also a build that already carries its distro,
and that one installs with no network at all.

<b>Storage</b>

Access to phone storage is optional and is never requested at startup. Turn it on and
internal storage shows up at ~/sdcard, an SD card at ~/sdcard-1. Leave it off and
everything else still works.

<b>Privacy</b>

No ads, no tracking, no account, and nothing sent to the developer. The app goes online
only when you ask it to download something.
